# НЕ ОБОРАЧИВАЙСЯ (ShadowStalker Horror Game)

3D хоррор-игра от первого лица на WebGL / Three.js с процедурным лабиринтом, кастомным анимированным 3D-монстром ShadowStalker из Blender и полной адаптацией под ПК и мобильные устройства (сенсорное управление).

---

## 🎮 Особенности

- **Кастомный 3D-монстр ShadowStalker**: Экспортирован напрямую из Blender с полным скелетом (`Armature`) и 6 запечёнными анимациями (`IDLE`, `WALK`, `RUN`, `ATTACK`, `SCARE`, `DEATH`).
- **Интеллектуальный AI**:
  - Патрулирование лабиринта со сменой маршрутов.
  - Режим преследования и обнаружения игрока по зрению и слуху (шаги, бег).
  - Скримеры и уникальные кинематографичные атаки.
- **Мобильное управление (Touch UI)**:
  - Динамический виртуальный джойстик перемещения слева.
  - Свайпы по экрану справа для свободного обзора камерой.
  - Сенсорные кнопки: Бег (Sprint), Задержка дыхания (Hold Breath), Взаимодействие (Interact), Пауза.
  - Автоматическая адаптация разрешения рендера (Dynamic DPI Scaling) для стабильных 60 FPS на смартфонах.
  - Подсказка ориентации экрана (альбомный режим).
- **ПК управление**:
  - `W, A, S, D` — перемещение.
  - `Мышь` — Pointer Lock обзор камерой.
  - `Shift` — спринт (расходует выносливость).
  - `Space` — задержка дыхания (снижает шум и скрывает от монстра).
  - `E` — взаимодействие с дверями и записками.
  - `F` — фонарик.
  - `Escape / P` — пауза.
- **Звуковая атмосфера**: Процедурный пространственный 3D-звук на Web Audio API (эмбиент, шаги, рыки монстра, сердцебиение, скримеры).

## 🚀 Локальный запуск

1. Склонируйте репозиторий:
```bash
git clone https://github.com/sapsrov32-lgtm/shadowstalker-horror.git
cd shadowstalker-horror
```

2. Запустите любой локальный HTTP-сервер:
```bash
# Вариант 1 (Python):
python -m http.server 8000

# Вариант 2 (Node.js npx):
npx serve .
```

3. Откройте `http://localhost:8000` в браузере.
*(Игра также поддерживает запуск напрямую через `index.html` двойным кликом благодаря встроенному fallback `shadowstalker_model.js`).*
